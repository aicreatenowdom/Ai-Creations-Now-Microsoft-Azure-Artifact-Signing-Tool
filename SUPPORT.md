- Product page: https://aicreatenow.com/azuretool.html
- Company support: https://aicreatenow.com/faq.html
- Email: info@aicreatenow.com
- Toll-free: 1-866-315-4750

## Before contacting support

Include the Azure Signing Tool version, Windows edition/build, whether it was run as administrator, the exact workflow stage, and the complete redacted error message. Do not publish passwords, MFA codes, tokens, tenant IDs, subscription IDs, certificate identifiers, customer data, private logs, or selected-file information in a public issue.

GitHub issues are for public documentation corrections and reproducible non-sensitive Azure Signing Tool defects. Azure account access, identity validation, certificate-profile, billing, and Microsoft service-enforcement matters must be handled with Microsoft through its official support channels.
