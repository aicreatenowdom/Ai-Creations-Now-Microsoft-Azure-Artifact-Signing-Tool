# Azure Signing Tool Security Policy

Do not post Microsoft credentials, MFA codes, tokens, tenant identifiers, subscription identifiers, certificate-profile data, customer information, selected-file details, or private logs in a public GitHub issue.

Report security-sensitive Azure Signing Tool concerns privately through:

- https://aicreatenow.com/
- info@aicreatenow.com
- 1-866-315-4750

Verify the executable only from the official product page or this repository's release assets. Compare the published SHA-256 value and inspect the Windows Authenticode signature before execution.

Security and compatibility attention is focused on the latest published production release. Please allow reasonable time for private review before publishing vulnerability details.
