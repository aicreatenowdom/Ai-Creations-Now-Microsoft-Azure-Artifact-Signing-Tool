# Release 1.0.21

## AI Creations Now Azure Signing Tool for Windows x64

Version 1.0.21 is the first public GitHub release of the portable Azure Artifact Signing workflow application.

### Included workflow

- Mandatory first-run privacy and installation agreement
- System-readiness checks and automatic preparation of missing Microsoft prerequisites
- Microsoft browser authentication with tenant-specific recovery when required
- Optional protected saved session with visible sign-out controls
- Azure subscription, Artifact Signing account, certificate-profile, and endpoint discovery
- Local executable selection and verified unsigned backup
- Microsoft Azure Artifact Signing and timestamping
- Windows Authenticode verification
- Before-and-after SHA-256 values
- Three-page local PDF verification report

### Important requirements

The application is for customers who already have an eligible Microsoft Azure subscription, Artifact Signing account, active certificate profile, and permission to sign. It does not create or sell signing certificates.

### Source policy

No proprietary source archive is published. GitHub's automatically generated source ZIP/TAR links contain only the public documentation repository.
